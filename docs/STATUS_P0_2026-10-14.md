- A correção de transição de níveis e o rastreamento first-party foram migrados no Supabase.
- O registro financeiro não depende mais de atribuição à campanha ou jornada.

- Snapshot do Short.io é apresentado apenas como observação, sem uso causal.

- `npm run typecheck` e `npm run build` foram aprovados.

## Pendências para aceite operacional

1. Publicar a versão no VPS. O ambiente web ainda não contém a rota first-party e respondeu 502 em server functions; push no Git não executa esse deploy.
2. Reprocessar os `webhook_logs` pendentes ou com erro pela versão publicada, em lotes idempotentes e monitorados. A auditoria de 14/10 encontrou backlog desde 02/10, principalmente na Sorte Alta.
3. Configurar HMAC junto às casas. Os seis tenants têm token de webhook, mas nenhum `webhook_secret`; preencher essa chave somente no BetLeads recusaria os callbacks atuais.

Essas três dependências não devem ser simuladas ou forçadas: elas alteram integração de produção e exigem publicação/configuração coordenada.
